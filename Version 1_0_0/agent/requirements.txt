# ============================================================================
# Agent Requirements
# ============================================================================
#
# Migration strategy:
#   Phase 1  -> Contracts / Transport Interface Foundation
#   Phase 2  -> Core / Dispatcher / Command Execution Separation
#   Phase 3  -> Legacy Kafka Transport Integration & Semantics
#   Phase 4  -> Persistence / SQLite Spooler
#   Phase 5  -> Gateway HTTP/mTLS Transport
#   Phase 6  -> Reliability / Retry / Circuit Breaker / Idempotency
#   Phase 7  -> Security / Health / Observability
#   Phase 8  -> Windows Service / Deployment
#
# Important:
#   Dependencies are grouped by the migration phase in which they are
#   actually required. Existing Legacy dependencies remain available until
#   the corresponding migration phase proves that they can be removed.
#
# Do NOT add a dependency merely because a future target-architecture
# component exists. Add it when the corresponding phase actually requires it.
# ============================================================================
